## 4. Windows shell quirks

- **Failed checks:**

- **Friction (insights):** "Shell and environment failures (heredocs, WSL path resolution, …)", plus PowerShell quoting.
- **Audit A7 (low):** the `gh: unknown shorthand flag` row may be a one-time slip. It happened once (F17).

> **Edit 4, `SKILL.md` "When a step fails":** replace the one-time `gh … -c` row with: "**An argument starting with `/`, or `ref:path`, arrives as `C:/Program Files/Git/…`** | Git Bash path conversion | prefix the command with `MSYS_NO_PATHCONV=1`". Line count stays the same.
